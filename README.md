## 🛠 Features
* **Zero-Latency Pre-Caching:** Audio files buffer into local memory on page load.
* **Toggle Playback:** Click any active button to stop its audio stream instantly.
* **Master Stop:** Global cut button to kill all active overlapping audio instances.
* **Google Sites Embed Ready:** Clean iframe compatibility using relative paths.
